# Website Company Profile - PT. Mega Karya Maritim (Mega Karya Group)

Website company profile modern, responsif, dan elegan untuk **PT. Mega Karya Maritim (Mega Karya Group)** yang dikembangkan berdasarkan referensi brosur resmi perusahaan dengan penyesuaian alamat kantor, kontak, dan integrasi WhatsApp serta fitur dwibahasa (Bilingual ID / EN).

---

## 🚀 Fitur Unggulan

1. **Dual Language (Bilingual Switching ID & EN)**:
   - Tombol switch interaktif (Indonesia 🇮🇩 & English 🇬🇧) di navigasi.
   - Mengubah seluruh konten teks, judul, deskripsi, form placeholder, dan meta tag secara instan tanpa reload halaman.
   - Pilihan bahasa otomatis tersimpan di `localStorage` peramban pengunjung.

2. **Integrasi Tombol & Formulir WhatsApp**:
   - **Floating WhatsApp Button** di sudut kanan bawah dengan efek *pulsing ripple*.
   - Popover interaktif untuk memulai percakapan cepat.
   - Tombol CTA WhatsApp di Hero Section, Layanan, dan Banner.
   - **Formulir Kontak Cepat**: Otomatis memformat nama, nomor telepon, email, layanan yang dipilih, dan pesan ke dalam format pesan WhatsApp yang rapi dan terkirim langsung ke nomor **0821-7220-0082**.

3. **SEO (Search Engine Optimization) Komprehensif**:
   - Tag Meta Standar: `<title>`, `meta description`, `keywords`, `robots`.
   - Semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`).
   - Open Graph (OG) Tags untuk pratinjau media sosial (Facebook, LinkedIn, WhatsApp).
   - Twitter Card Tags.
   - **Schema.org Structured Data (JSON-LD)** untuk tipe `Corporation` / `LocalBusiness`.
   - Berkas `robots.txt` dan `sitemap.xml` yang valid.

4. **Desain Maritim Modern & Responsif**:
   - Mengikuti struktur brosur: **Tentang Kami**, **Visi & Misi**, **5 Nilai Perusahaan** (*Integrity, Professionalism, Commitment, Global Mindset, Excellence*), **3 Layanan Utama** (*Crew Manning Agency, Crew Management Services, Crew Recruitment*), **Keunggulan (Mengapa Memilih Kami)**, dan **Jangkauan Layanan Domestik & Internasional**.
   - Dilengkapi *embed map* lokasi kantor Kebayoran Lama.

## 💻 Cara Menjalankan

Anda cukup membuka berkas `index.html` langsung di browser apapun (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari) atau menjalankan local server:

```powershell
# Contoh menggunakan Python HTTP server (opsional):
python -m http.server 8000
```
Lalu buka `http://localhost:8000` pada peramban Anda.
